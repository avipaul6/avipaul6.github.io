How I build
01

Governance is a feature

An agent that takes real actions has to earn being left running. Mine refuse, ask, and log.

02

The model finds, code computes

LLMs are good at finding and reasoning. Anything a person acts on, deterministic code does, so the numbers are right.

03

Build in the open

The wins and the failure modes both go public. That is most of the credibility.
